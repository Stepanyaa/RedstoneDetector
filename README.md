A powerful Minecraft plugin designed to automatically detect and prevent redstone-based lag machines on your server. It features an intuitive, highly interactive GUI interface for monitoring, sorting, and managing suspicious chunks in real-time.

## **✨ Why Choose RedstoneDetector?**
Tired of spending hours hunting for that one hidden lag machine dropping your TPS? RedstoneDetector automates the process, transforming a complex administrative nightmare into a simple, manageable task. It acts as the **proactive defense** your server needs against malicious or unoptimized setups, allowing you to focus on what matters—your community. 

### **🚀 Key Features**

* 🔍 **Automatic Detection** – Passively scans chunks for excessive redstone components and entities without lagging the server.
* 🛡️ **Smart TPS Protection** – Automatically freezes redstone activity in problematic chunks when your TPS drops below a customizable threshold (Default: 15.0 TPS).
* 📊 **Advanced Visual GUI** – Easy-to-use menu for real-time monitoring. Sort chunks by **Coordinate, Redstone count, or Entity count**!
* ⚡ **Quick Actions** – Teleport directly to suspicious chunks, remove block updates, or clear redstone/entities with just one click.
* ⚙️ **Highly Configurable** – Customize limits for max redstone (Default: 100), max entities (Default: 100), freeze durations, and chunk scanning speeds.
* 🌍 **Multi-language Support** – Built-in support for EN, RU, DE, FR, TR, PL, and PT.

## **🛠 Technical Info & Compatibility**

* **Core API:** Bukkit / Spigot / Paper / Purpur
* **Hybrid Server Support:** ✅ Fully compatible with **Mohist**, **Arclight**!
* **Versions:** 1.16.1 – 1.21.x
* **Folia:** ❌ Not Supported

---

## **📜 Commands & Permissions**

| Command | Permission | Description |
|---------|------------|-------------|
| `/rd gui` | `redstonedetector.gui` | Opens the main monitoring and management interface. |
| `/rd scan` | `redstonedetector.scan` | Manually trigger a scan for redstone lag machines. |
| `/rd redstone <freeze/unfreeze/status>` | `redstonedetector.redstone` | Globally freeze, unfreeze, or check redstone status. |
| `/rd reload` | `redstonedetector.reload` | Reloads the plugin's configuration files. |

> **Note:** The permission `redstonedetector.admin` grants full access to all plugin features (Defaults to OP).

# **🔴 RedstoneDetector (Русская версия 🇷🇺)** **Ультимативная защита вашего сервера от лаг-машин!**

</div>

Мощный плагин для Minecraft, предназначенный для автоматического обнаружения и предотвращения лаг-машин на основе редстоуна. Оснащен интуитивно понятным интерактивным GUI-интерфейсом для мониторинга, сортировки и управления подозрительными чанками в реальном времени.

## **✨ Почему стоит выбрать RedstoneDetector?**
Устали тратить часы на поиск одной-единственной скрытой машины, которая убивает ваш TPS? RedstoneDetector автоматизирует этот процесс, превращая сложную административную задачу в простую и выполнимую. Это **проактивная защита** вашего сервера от намеренных лагов или неоптимизированных механизмов, позволяющая вам сосредоточиться на главном — на вашем сообществе.

### **🚀 Основные возможности**

* 🔍 **Автоматическое обнаружение** — Пассивно сканирует чанки на наличие избыточных редстоун-компонентов и сущностей без нагрузки на сервер.
* 🛡️ **Умная защита TPS** — Автоматическая заморозка редстоуна в проблемных чанках при падении TPS ниже заданного порога (по умолчанию 15.0).
* 📊 **Продвинутый визуальный интерфейс** — Удобное GUI-меню для мониторинга. Сортируйте чанки по **Координатам, количеству Редстоуна или Сущностей**!
* ⚡ **Быстрые действия** — Телепортация к подозрительным чанкам, удаление или заморозка схем всего в один клик.
* ⚙️ **Глубокая настройка** — Настраивайте лимиты редстоуна (по умолчанию 100), сущностей (по умолчанию 100), время заморозки и скорость сканирования чанков.
* 🌍 **Поддержка языков** — Встроенная поддержка EN, RU, DE, FR, TR, PL, PT.
